## Cómo agregar tus trabajos HTML

1. Crea las cinco carpetas con los nombres indicados.
2. Copia el HTML de cada trabajo en su carpeta.
3. Para que el enlace funcione tal como está, nombra el archivo principal de cada carpeta `index.html`.
4. Si tus trabajos usan archivos auxiliares (CSS, JavaScript, imágenes o datos), copia también esos archivos y conserva sus rutas relativas.
5. Sube todo al repositorio de GitHub.

## Activar GitHub Pages

1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.

El dashboard ya contiene enlaces relativos a las cinco carpetas. No incluye los HTML de los trabajos porque deben copiarse desde tus archivos originales.
